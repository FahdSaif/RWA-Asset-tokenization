# Knowledge-base scenarios (post-registration)

Extra rule files for `tools/kb_scenarios.py`. Each folder is added on top of the frozen
rules in `kb/`. They are "what if" cases, not claims that these rules apply today.
The plan is in `docs/KB_SCENARIOS_PLAN.md`. Scenarios S4a, S4b and S4c need no folder:
they change the jurisdictions or leave out the retention rules.
